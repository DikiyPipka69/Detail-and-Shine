# Detail & Shine — лендинг с формой записи

Портфолио-проект: лендинг мобильного автодетейлинга с формой заявки,
которая реально сохраняется в базу через FastAPI, плюс закрытая
админ-панель для просмотра заявок. Тема отличается от Card Catalog
специально — чтобы в портфолио было видно диапазон стилей, а не один
и тот же визуальный шаблон.

## Что показывает этот проект (в отличие от Card Catalog)

- **Лендинг для реального клиентского сценария** — то, что чаще всего
  заказывают у фрилансера: сайт с формой "оставить заявку"
- **Разделение публичного и приватного** — форма открыта всем, но
  список заявок закрыт токеном администратора
- **Другой визуальный язык** — тёмная палитра, `Barlow Condensed` для
  заголовков вместо засечного шрифта в первом проекте

## Запуск

```
cd backend
pip install -r requirements.txt
uvicorn app.main:app --reload
```

- Лендинг: **http://localhost:8000**
- Админка: **http://localhost:8000/admin.html**

## Токен администратора

По умолчанию токен — `changeme` (для локальной разработки). Введи его
на странице `/admin.html`, чтобы увидеть список заявок.

**Перед деплоем обязательно смени токен** — задай переменную
окружения `ADMIN_TOKEN` со своим значением (в настройках Render это
делается там же, где мы указывали `PYTHON_VERSION`). Без этого шага
любой, кто узнает слово "changeme", сможет увидеть все заявки клиентов.

## Как это устроено технически

- Эндпоинт `POST /api/leads` — публичный, без проверки токена,
  потому что форму должен уметь отправить любой посетитель сайта
- Эндпоинты `GET /api/leads` и `DELETE /api/leads/{id}` защищены через
  FastAPI `Depends` с проверкой заголовка `X-Admin-Token` — это самый
  простой вид защиты, которого достаточно для одного администратора
  без необходимости в полноценной системе логинов с базой пользователей
- Токен хранится в `sessionStorage` браузера админа (не в localStorage) —
  значит при закрытии вкладки нужно будет ввести его заново, что
  чуть безопаснее для случайно оставленного открытым компьютера

## Деплой (Render, бесплатно)

Так же, как Card Catalog:

1. Залей на GitHub
2. render.com → New → Web Service → подключи репозиторий
3. Root Directory: `backend`
4. Build Command: `pip install -r requirements.txt`
5. Start Command: `uvicorn app.main:app --host 0.0.0.0 --port $PORT`
6. **Обязательно добавь Environment Variable:**
   - `PYTHON_VERSION` = `3.12.7`
   - `ADMIN_TOKEN` = свой собственный секретный токен (не `changeme`!)
